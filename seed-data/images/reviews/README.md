Put real seeded product review photos here.

Directory shape:

- `<shop-slug>/<product-slug>/<reviewer-email-slug>/image-1.jpg`
- `<shop-slug>/<product-slug>/<reviewer-email-slug>/image-2.jpg`

Example:

- `olive-atelier/canvas-market-tote/member-example-com/review-1.jpg`
- `olive-atelier/canvas-market-tote/member-example-com/review-2.jpg`

Notes:

- `reviewer-email-slug` is the slugified `user_email` from `product-reviews.tsv`.
- Files are sorted alphabetically and the first `image_count` files are attached.
- Supported extensions are `.jpg`, `.jpeg`, `.png`, and `.webp`.
